# Git 面板

Git 面板让你直接在 Infernux 编辑器里完成暂存、取消暂存和提交，不用切到终端。

## 打开面板

你可以在菜单栏的 `扩展/Git 集成` 找到它。

## 开始之前

面板作用于当前在编辑器中打开的项目文件夹。如果这个文件夹还不是 Git 仓库，面板不会显示正常界面，而是显示「创建 Git 仓库」视图。点击**创建 Git 仓库**会对项目文件夹执行 `git init`，之后面板自动切换到正常界面。

系统必须已安装 Git，并且 Editor 启动时能在 `PATH` 中找到它。否则面板不会显示文件列表，而会显示一条简短提示。

## 面板结构

正常界面从上到下分四部分：

- **源代码管理** —— 标题栏。标题栏显示项目当前所在的分支，点击即可打开分支列表。右侧的刷新图标会立即执行一次 `git status`，跳过刷新间隔。
- **已暂存的更改** —— 下次提交会包含的文件。
- **更改** —— 已修改或删除、但还没暂存的文件，以及未跟踪的文件。
- **提交区** —— 消息输入框和**提交**按钮。

一个文件可以同时出现在两个列表里。例如某个文件暂存之后又被修改，它会同时显示在「已暂存的更改」和「更改」中，这样你能看出它既有已暂存的内容，也有未暂存的改动。

## 怎么读一行文件

每一行文件包含三部分信息：

- **状态图标**，表示变更类型：新增、修改、删除、重命名、复制、冲突、未跟踪或已忽略。
- **文件路径。**
- **Git 状态码**，并按变更类型着色——新增为绿色，修改为黄色，删除为红色，未跟踪为青色，重命名为蓝色，冲突为橙色。状态码保留 Git 原本的写法，因此像 `AM` 这样的双状态依然可读。悬停在状态码上可以看到该变更的名称。

行尾是这个文件对应的操作按钮。

## 暂存与取消暂存

- 暂存单个文件：点击「更改」中该文件右侧的 `+` 图标。
- 一次性暂存「更改」里的全部文件：点击**暂存全部**。
- 取消暂存：点击「已暂存的更改」中该文件右侧的 `−` 图标。仓库还没有任何提交时，这个操作同样可用。

**暂存全部**等价于 `git add -A`：修改、新增和删除都会被暂存。

## 提交

- 在消息输入框中填写提交信息。你在面板里继续操作时，输入的内容不会丢失。
- 点击**提交**，提交会被创建，文件列表随即刷新。
- 如果消息输入框为空，点击**提交**不会有任何效果，需要先填写提交信息。

## 刷新文件列表

面板会自动更新文件列表，最多每秒一次。如果你想立刻看到当前状态——比如刚在终端里执行过 Git 命令——点击标题栏右侧的刷新图标。

## 切换分支

标题栏会显示项目当前所在的分支，以及它的上游和与上游的偏差（`↑2 ↓1`）。点击分支名可以打开分支列表。

- 列表先列本地分支，再列远端分支。当前分支前面有一个圆点标记，跟踪了别的分支的条目会在右侧显示它的上游。
- 在过滤框里输入内容可以缩小列表范围。过滤只是改变显示内容，不会执行任何命令。
- 点击某个分支即可切换过去。切换在后台执行，即使在大仓库里面板也不会卡住。
- 在底部的输入框里填写名字并点击**创建**，就会从当前提交新建一个分支并切换过去。分支名可以包含 `/`，例如 `feature/new-panel`。

如果切换失败——通常是因为工作区有改动，而目标分支会覆盖它们——弹窗会用一句话说明出了什么问题，并指向 Console，完整的 Git 信息都留在那里。弹窗提供**打开 Console**、**复制详情**和**关闭**三个按钮。

## 故障排查

**面板提示当前环境无法使用 Git。** 系统没有安装 Git，或者 Editor 启动时的 `PATH` 里找不到它。安装 Git 后重启 Editor。

**点击提交没有任何反应。** 消息输入框是空的，需要先填写提交信息。

**`git commit` 报错询问你的身份。** Git 还没有配置用户信息，执行：

```bash
git config --global user.name "你的名字"
git config --global user.email "you@example.com"
```

**新建的文件一直留在「更改」里。** 未跟踪的文件会标记为 `?`，直到被暂存。

**图标没有显示。** 图标是矢量素材，由编辑器在面板首次打开时完成光栅化。如果 Editor 启动时没有 GPU 支持，或者纹理上传失败，面板会退回到纯文字控件，状态码仍然正常工作。

**操作失败，但面板看起来毫无变化。** 面板会把失败原因写进 Editor 的 Console。打开 Console 窗口就能看到——完整的 Git 输出都留在那里，关闭提示之后依然可以回看。
