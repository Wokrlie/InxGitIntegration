# Git 面板

Git 面板让你直接在 Infernux 编辑器里完成暂存、取消暂存和提交，不用切到终端。
## 打开面板
你可以再菜单栏的`插件/Git集成`
# 开始之前

面板作用于当前在编辑器中打开的项目文件夹。如果这个文件夹还不是 Git 仓库，面板不会显示正常界面，而是显示 Create Git Repository 视图。点击 Create Git Repository 会对项目文件夹执行 git init，之后面板自动切换到正常界面。
## 面板结构

正常界面从上到下分三部分：

 -  Staged Changes —— 下次提交会包含的文件。

 -  Changes —— 已修改或删除、但还没暂存的文件。

 -  提交区 —— 消息输入框、Commit 按钮和 Refresh 按钮。

一个文件可以同时出现在两个列表里。例如某个文件暂存之后又被修改，它会同时显示在 Staged Changes 和 Changes 中，这样你能看出它既有已暂存的内容，也有未暂存的改动。
暂存与取消暂存

 -  暂存单个文件：点击 Changes 中该文件右侧的 + 按钮。

 -  一次性暂存 Changes 里的全部文件：点击 Stage all。

 -  取消暂存：点击 Staged Changes 中该文件右侧的 − 按钮。仓库还没有任何提交时，这个操作同样可用。

## 提交

 -  在消息输入框中填写提交信息。你在面板里继续操作时，输入的内容不会丢失。

 -  点击 Commit，提交会被创建，文件列表随即刷新。

 -  如果消息输入框为空，点击 Commit 不会有任何效果，需要先填写提交信息。

## 刷新文件列表

面板会自动更新文件列表。如果你想立刻看到当前状态——比如刚在终端里执行过 Git 命令——点击 Refresh。
## 后续计划

后续版本将支持分支显示与切换、文件状态着色、未暂存文件的丢弃改动、Push / Pull 控制以及 diff 预览。
